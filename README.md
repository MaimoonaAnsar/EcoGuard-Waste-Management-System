# EcoGuard – Waste Management System🌳🥬

**EcoGuard** is a web-based waste management system designed to improve how waste-related services are managed and coordinated between citizens and local authorities.The system was designed as our final project in our Diploma in Software Engineering we later improvised it by adding more features as per the guidance provided 

The system provides a digital platform where citizens can report waste-related issues, request special waste pickups, participate in environmental activities, and access relevant waste management services.

### Special Pickup Request Feature

The system includes a **Special Pickup Request Management** feature that allows citizens to submit requests for waste collection. Divisional Secretariat (DS) officers can then:

* View special pickup requests submitted by citizens
* View citizen and pickup details
* View the pickup location on an interactive **Leaflet map**
* Check the requested pickup date and waste type
* Review additional notes provided by citizens
* Schedule or reject requests
* Mark scheduled pickups as completed
* Track request statuses such as **Pending, Scheduled, Completed, and Rejected**

The feature follows a simple **Citizen → DS** workflow, keeping the process straightforward while providing an organized way to manage special waste collection requests.

### Technologies used

* PHP
* MySQL
* HTML, CSS & JavaScript
* Bootstrap
* Leaflet.js
* XAMPP

EcoGuard aims to make waste management more **organized, accessible, and efficient** through a centralized digital platform.
